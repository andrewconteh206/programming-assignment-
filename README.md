# Digital Exam & Results Management System

## Overview
A modular Python console application developed for educational institutions under Digital Public Goods (DPG) standards. It handles student registrations, course enrollments, and exam results tracking using Object-Oriented Programming (OOP).

## DPG Alignment
- **Open Source:** Available freely under standard open-source practices.
- **Privacy-Respecting:** Does not store sensitive personal data or physical identity documents.
- **Modular & Reusable:** Separates data structure operations cleanly into class hierarchies (`Student` and `Course`).

## Sample Output
Run the program using:
python exam_portal.py
